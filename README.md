The Kicad files, GAL JEDEC, and original bios necessary to produce the Mr. Backup Z64 Hardware Version 3.0.

All PCB's 1.6 mm thick except the N64 Connector Board. That is 1.2 mm.

Only one of the two DRAM footprints is populated: U2.

Power supply must strictly be 5V.

The LCD is a HD44780 and the exact replacement you need can be found [here](https://www.buydisplay.com/3-3v-or-5v-display-lcd-20x2-arduino-connection-hd44780-i2c-character?srsltid=AfmBOopgijVY8Rs8OAxd6UK98-_H8I7qiL7LEyb3Y3IFNYg6rj2Kj3Jj). Make sure you select the 5V model with the 2x8 pin header.
